# Strix

One-page website for Strix, a phone accessories brand (cases, power banks, cables, screen glass).

Plain HTML, CSS and JavaScript. No build step: open `index.html` through any static server, or enable GitHub Pages on the `main` branch.

- `index.html` - page content
- `styles.css` - all styling, light and dark mode
- `main.js` - scroll reveal and newsletter form validation
- `assets/` - logo and product photography
